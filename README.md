**Pitch Trajectory Plots**
---
Reports shown pregame to hitters to prepare for opposing pitchers.

**Details**

Plots trajectories of most recent 20 pitches of a certain pitch type to a certain handedness for an opposing pitcher.

Each pitch is given a run value of a swing, red is high and blue is low.

20 pitches are shown to go to the hitter's decision point. Average of 5 highest and lowest swing decision run values are extended to strike zone. Average of all 20 is also extended in gray.
